# I'm Nomagno, a Computer Science student and amateur musician
- I have experience to varying degrees with C, C++, Java, Rust, Python, Haskell, Scheme, JavaScript, Bash, Forth, and GDScript (Godot development in general).
- I composed and produced the musical score for an upcoming animated short by a friend.
- I have various sorts of experience on programming language development: I am the author of the C dialect [PreC](https://github.com/Nomagno/PreC) along with its own portable compiler, as well as the author of [nomforth](https://github.com/Nomagno/nomforth), a Forth dialect. For various proglang experiments, see my [Github Gist](https://gist.github.com/Nomagno).
- I am a contributor to [Ratty](https://github.com/orhun/ratty), a terminal written in Rust that allows to display 3D models as part of the text. I expanded the Ratty Graphics Protocol to allow more control by applications over how the 3D content is displayed.
- I am the author of [NDS-NetworkedInput](https://github.com/Nomagno/NDS-NetworkedInput), an original application server written in C to control your computer with your DS or 3DS system (plus a client forked from Louisvh's NDS-controller).
- I have some experience contributing to FOSS racing game [SuperTuxKart](https://github.com/SuperTuxKart/stk-code), specially to the upcoming 2.0 release. Additionally, I am the author of [SuperTuxKart: Tyre Mod Edition](https://github.com/Nomagno/stk-code), a version of the game with its own design aspirations. It has fuel simulation, tyre degradation, pit stops, better flexibility and user experience for online events, and far more configurability such that players can pick their own rules. It also improves hundreds of minor aspects over the base game.
- I am the author of the long-term WIP project [Halfive](https://github.com/Nomagno/Halfive), aiming to make an engine and ecosystem for a 2D racing game entirely in freestanding C, including the physics engine, renderer, and network protocol. It can run on both native platforms, and WebAssembly (WASM through Emscripten).
  - As sub-projects, Halfive includes its own VM with a custom Instruction Set Architecture (ISA) and assembler, a static site generator (SSG), a website with its own auto-updated statistics and an RSS feed.
- I maintained [Teloren](https://github.com/zesterer/teloren) (A terminal client to FOSS open-world RPG "[Veloren](https://veloren.net)", by zesterer, with both Teloren and Veloren being written in Rust) for around three months over on GitLab and added a few significant features like group invitation support and basic inventory support.
